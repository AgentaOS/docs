A product is one thing you sell at one price. It is a one-time payment or a subscription billed monthly or yearly. Every product has a buyer link, a public URL in the shape `https://app.agentaos.ai/pay/…`. You share that link, and each buyer who opens it gets their own checkout. One link can be paid any number of times.

AgentaOS is the merchant of record for card and bank sales. The checkout asks for the buyer's country, adds the correct VAT, and issues the invoice. You do not register for VAT in the buyer's country. See [How merchant of record works](/mor/how-it-works).

The API calls a product a payment link. Both names mean the same object, and the product's ID is the `linkId` in the API.

## Create a product in the dashboard

<Steps>
  <Step title="Open the form">
    In the sidebar, click **Products**. Then click **New product**.
  </Step>
  <Step title="Fill in the details">
    Under **Details**, enter the **Product name** and a **Description**. Add a **Product image** if you want one. The buyer sees all three on the checkout.
  </Step>
  <Step title="Set the price">
    Under **Pricing**, enter the price and pick **EUR** or **USD**. Choose **One-time** or **Subscription**. For a subscription, pick **Monthly** or **Yearly**.
  </Step>
  <Step title="Set a redirect (optional)">
    Under **After payment**, click **+ Redirect buyers after payment**. Enter a **Success URL** and a **Cancel URL**.
  </Step>
  <Step title="Create the product">
    Click **Create product**. The confirmation screen shows the product as live, with **Copy link** to copy its buyer link.
  </Step>
</Steps>

The **Summary** panel on the right of the form recaps the product as you type. Click **Preview** to see the product the way a buyer sees it.

In test mode, the confirmation screen shows **Try a test payment**. Use card `4242 4242 4242 4242`, any future date, and any CVC. Nothing is charged. See [Test mode and live mode](/getting-started/test-mode).

### Subscriptions and trials

When you choose **Subscription**, two more fields appear. **Free trial (days)** delays the first full charge by that number of days, up to 730. **Trial price** sets what the whole trial costs; leave it empty for a free trial. See [Subscriptions](/payments/subscriptions) for what happens after the buyer subscribes.

In live mode, **Subscription** stays locked until your business is verified. See [Go live](/guides/go-live).

### VAT on your prices

The Products page shows how VAT applies to your prices: **VAT added at checkout** or **Prices include VAT**. Click **Change** next to it to set the default for your account under **Settings → Business**. The **Prices include VAT** checkbox on the product form changes it for that one product.

## Share the buyer link

Every product row on the Products page has a copy button that copies the buyer link. Send that link by email or in a chat, or put it behind a Buy button on your site.

The link carries no information about who the buyer is. When your app must know which of your users paid, create a checkout from your server instead. See [Checkouts](/payments/checkouts#create-a-checkout-from-your-server).

To show the checkout inside your own page, open the product and use **Embed on your site**. See [Embedded checkout](/payments/embedded-checkout).

## Custom checkout fields

A product can ask the buyer extra questions before they pay, such as an attendee name or a company. The checkout shows these fields under the line **Asked by** followed by your business name. Each field is required or optional.

You add custom fields through the API with `checkoutFields`. The product form in the dashboard does not have them.

```typescript
const link = await agentaos.paymentLinks.create({
  amount: 15,
  currency: 'EUR',
  name: 'Event ticket',
  checkoutFields: [
    { key: 'attendeeName', label: 'Attendee name', type: 'text', required: true },
    { key: 'company', label: 'Company', type: 'text', required: false },
  ],
});
```

Each field has a `key`, a `label`, a `type` (`text`, `email`, `tel`, or `select`), and `required`. It can also have a `placeholder`, and `options` for `select`.

## From code

You can create and manage products with the SDK, the CLI, or the REST API. The full parameter and response reference is in [Payment links (SDK)](/sdk/pay-payment-links) and [agenta products](/cli/products).

### Create a product

<Tabs>
  <Tab title="SDK">
    ```typescript
    import { AgentaOS } from '@agentaos/pay';

    const agentaos = new AgentaOS(process.env.AGENTAOS_API_KEY!);

    const link = await agentaos.paymentLinks.create({
      amount: 49.99,
      currency: 'EUR',
      name: 'Pro plan',
      successUrl: 'https://myshop.com/success',
      cancelUrl: 'https://myshop.com/cancel',
    });

    console.log(link.checkoutUrl);
    // https://app.agentaos.ai/pay/7rr6S9ml4BMp829wV5WeAA
    ```
  </Tab>
  <Tab title="CLI">
    ```bash
    agenta products create --name "Pro plan" --amount 49.99 --currency EUR \
      --success-url https://myshop.com/success
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl -X POST https://api.agentaos.ai/api/v1/gateway/payment-links \
      -H "x-api-key: sk_live_..." \
      -H "Content-Type: application/json" \
      -d '{ "amount": 49.99, "currency": "EUR", "name": "Pro plan" }'
    ```
  </Tab>
</Tabs>

`amount` is in currency units: `49.99` means €49.99, not cents. See the [money model](/api-reference/introduction#money-model). The CLI creates test-mode products; create live products in the dashboard.

### One-time vs. subscription

A product is `type: 'one_time'` by default. Every payment is independent, and the link can be paid any number of times. Set `type: 'subscription'` to make a recurring plan. A subscription needs a `billingInterval`.

```typescript
const plan = await agentaos.paymentLinks.create({
  amount: 29.99,
  currency: 'EUR',
  name: 'Pro plan, monthly',
  type: 'subscription',
  billingInterval: 'month', // 'month' | 'year'
  trialPeriodDays: 14, // optional, 1 to 730
});
```

<Warning>
Creating a subscription product does not create a subscription. A subscription starts only when a buyer pays the product at the checkout. See [Subscriptions](/payments/subscriptions).
</Warning>

### Retrieve, list, and cancel

<Tabs>
  <Tab title="SDK">
    ```typescript
    const link = await agentaos.paymentLinks.retrieve('link-uuid');

    const page = await agentaos.paymentLinks.list({ limit: 20, offset: 0 });
    console.log(page.total, page.hasMore);

    await agentaos.paymentLinks.cancel('link-uuid');
    ```
  </Tab>
  <Tab title="CLI">
    ```bash
    agenta products list --limit 20
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl https://api.agentaos.ai/api/v1/gateway/payment-links/link-uuid \
      -H "x-api-key: sk_live_..."

    curl "https://api.agentaos.ai/api/v1/gateway/payment-links?limit=20&offset=0" \
      -H "x-api-key: sk_live_..."

    curl -X DELETE https://api.agentaos.ai/api/v1/gateway/payment-links/link-uuid \
      -H "x-api-key: sk_live_..."
    ```
  </Tab>
</Tabs>

A list call returns `{ items, total, hasMore }`. Canceling a product stops new checkouts on its link. Checkouts already in progress and subscriptions already running from it continue.
