---
title: "Receipts"
description: "Every paid invoice gets a receipt, emailed to the buyer automatically. Download the PDF, or send the email again."
---

When a payment clears, AgentaOS emails the buyer a receipt at the email they gave at checkout. You do not send it or build it. The receipt belongs to the paid invoice, and you can send it again if the buyer loses it. AgentaOS also emails you when you make a sale.

A receipt exists only for a paid invoice. An open or voided invoice has no receipt.

## Send a receipt again

Resending goes to the buyer's email on the invoice, the same address as the first receipt. Only an owner or an admin can resend a receipt.

<Tabs>
  <Tab title="SDK">
    ```typescript
    const result = await agentaos.invoices.sendReceipt('invoice-uuid');
    console.log(result.sentTo); // the address it went to
    ```
  </Tab>
  <Tab title="CLI">
    ```bash
    agenta invoices send-receipt invoice-uuid
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl -X POST https://api.agentaos.ai/api/v1/gateway/invoices/invoice-uuid/send-receipt \
      -H "x-api-key: sk_live_..."
    ```
  </Tab>
</Tabs>

The call returns `{ ok: true, sentTo }`. It fails when the invoice is not paid, or when the invoice has no buyer email.

## Download the receipt PDF

<Tabs>
  <Tab title="SDK">
    ```typescript
    import { writeFileSync } from 'node:fs';

    const pdf = await agentaos.invoices.getReceipt('invoice-uuid');
    writeFileSync('receipt.pdf', pdf);
    ```
  </Tab>
  <Tab title="CLI">
    ```bash
    agenta invoices receipt invoice-uuid -o receipt.pdf
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl https://api.agentaos.ai/api/v1/gateway/invoices/invoice-uuid/receipt \
      -H "x-api-key: sk_live_..." \
      -o receipt.pdf
    ```
  </Tab>
</Tabs>

An invoice from before receipts existed on AgentaOS has no receipt document. For that invoice, the call returns the invoice PDF, which is also a proof of payment.
