Each guide starts from nothing and ends with a working result: one goal, one path. The Documentation tab is the reference to keep open in a second tab: it explains concepts and lists every parameter on every resource. Follow a guide from top to bottom. Where a concept needs more depth, the guide links to its Documentation page; read it, then return to the step you left.

<Info>
Every guide runs in **test mode** by default: a full test environment with test money, so there is nothing to verify and nothing to lose. See [Test mode and live mode](/getting-started/test-mode) if you haven't set that up yet.
</Info>

## Who these are for

These guides are for founders first: most of them start in the dashboard, in the screen's own words, and need no code. Developers come second: a guide shows the SDK, CLI, or API path after the dashboard steps, and Handle webhooks is for developers only.

If you're brand new to AgentaOS, start with the [Quickstart](/getting-started/quickstart). It covers account setup in more depth than these guides assume.
