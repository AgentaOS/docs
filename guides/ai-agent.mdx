By the end of this guide an AI agent can create checkouts, check payments and manage subscriptions for your store. You ask in plain words; the agent does the work.

There are two ways in. You can set up both; they do not conflict.

<CardGroup cols={2}>
  <Card title="Connect the MCP server" icon="plug">
    Claude.ai, ChatGPT, Claude Code or Cursor. You approve the connection once in the browser and paste no key.
  </Card>
  <Card title="Give a coding agent the CLI" icon="terminal">
    Any agent that runs shell commands, including one in CI. It uses the `agenta` CLI and the SKILL.md prompt.
  </Card>
</CardGroup>

## Before you start

You do not need an account up front. When you approve the connection or run `agenta login`, you sign in, and a new email creates your account.

## Path A: connect the MCP server

<Steps>
  <Step title="Connect your agent">
    Follow [MCP server](/mcp/setup) for your client. For Claude.ai or ChatGPT, follow [Connect Claude.ai or ChatGPT](/mcp/remote-connector). Pick **Test mode** on the approval page while you try things out.
  </Step>

  <Step title="Try a prompt">
    Ask your agent:

    > Create a checkout for 50 EUR for my consulting invoice.

    The agent calls `agenta_pay_checkout` and answers with the link to share, in a sentence like this one:

    ```text
    Checkout for €50.00 created. Share https://… with your customer.
    ```
  </Step>

  <Step title="Manage what you sold">
    Ask it directly:

    > List my last 5 checkouts.

    > Cancel the subscription for ana@example.com at the end of the current period.

    The agent calls the matching tools, such as `agenta_pay_list`, `agenta_subscriptions_list` and `agenta_subscriptions_cancel`, and reports back in the chat.
  </Step>
</Steps>

[MCP server](/mcp/setup#tools) lists every tool your agent can use.

## Path B: a coding agent with the CLI

<Steps>
  <Step title="Install the CLI and log in">
    ```bash
    curl -fsSL https://agentaos.ai/install | bash
    agenta login
    ```
    `agenta login` is the one step that needs you: it opens a browser for sign-in. Every command an agent runs after that is non-interactive.
  </Step>

  <Step title="Give your agent the skill">
    Tell your coding agent to fetch and follow the skill prompt:

    ```bash
    curl -fsSL https://agentaos.ai/SKILL.md
    ```

    It teaches the agent the `agenta` commands and their flags. It also tells the agent to run `agenta status --json` first and to pass `--json` to every command, so the output is JSON the agent can read.
  </Step>

  <Step title="Try a prompt">
    Ask it something like:

    > Create a checkout for 50 EUR for my consulting invoice.

    The agent runs `agenta status --json` to confirm payment tools are ready, then `agenta pay checkout -a 50 --json`, and hands you back the `checkoutUrl` to share with your client.
  </Step>
</Steps>

<Tip>
An agent connected in test mode, or running on a test key, sees and creates test data only. It cannot move real money.
</Tip>

## Verify it worked

Ask the agent:

> What's my AgentaOS status?

On the MCP path, the agent calls `agenta_status_get`. Before you go live, the answer starts with "Test payments work now." On the CLI path, the agent runs `agenta status --json` and reports `paymentTools.ready: true`, along with your organization.
