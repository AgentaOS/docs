---
title: "Get the fields a currency needs"
openapi: "GET /gateway/bank-accounts/requirements"
---

<Note>
The fields depend on the currency: an IBAN for EUR, a routing and an account number for USD. Render the schema, then send the answers to add the account. When a field is marked `refreshRequirementsOnChange`, send the answers so far to the refresh call and render the fields again.
</Note>
