---
title: "Revoke the invitation"
openapi: "DELETE /gateway/businesses/{id}/invitation"
---

<Note>
The open invitation's link stops working. Returns `204` with no body.
</Note>

<Note>
**Webhook:** none. An invitation changes no verification state. See [Which action fires which event](/webhooks/events#which-action-fires-which-event).
</Note>
