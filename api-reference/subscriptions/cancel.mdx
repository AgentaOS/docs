---
title: "Cancel a subscription"
openapi: "POST /gateway/subscriptions/{id}/cancel"
---

<Note>
Calling cancel again on an already-`canceled` subscription is a no-op. It returns the same result without hitting the card processor a second time. If the subscription never completed a first successful charge (`stripeSubscriptionId` is `null`), cancel returns `400`. There is no immediate cancellation: `atPeriodEnd: false` also returns `400`, and the subscription always runs to the end of the period the subscriber paid for.
</Note>

<Note>
**Webhook:** `subscription.updated` fires right away, when the call schedules the cancel. `subscription.canceled` fires when the period ends, on AgentaOS's next check. A repeat call sends nothing. See [Which action fires which event](/webhooks/events#which-action-fires-which-event).
</Note>
