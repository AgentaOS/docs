---
title: "Stop a discount code"
openapi: "POST /gateway/discount-codes/{id}/archive"
---

<Warning>
Needs a signed-in owner or admin. An API key is refused with `403`: create and stop codes in the dashboard, under **Discounts**.
</Warning>

<Note>
**Webhook:** none. Stopping a code changes no payment or subscription. See [Which action fires which event](/webhooks/events#which-action-fires-which-event).
</Note>
