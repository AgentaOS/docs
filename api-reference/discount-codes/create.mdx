---
title: "Create a discount code"
openapi: "POST /gateway/discount-codes"
---

<Warning>
Needs a signed-in owner or admin. An API key is refused with `403`: create and stop codes in the dashboard, under **Discounts**.
</Warning>

<Note>
**Webhook:** none. A discount code moves no money until a buyer uses it at checkout. See [Which action fires which event](/webhooks/events#which-action-fires-which-event).
</Note>
