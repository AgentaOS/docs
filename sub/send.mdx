# Send & Sign

## Send ETH

```bash
agenta sub send <to> <amount>
agenta sub send 0xRecipient 0.01 --network base-sepolia
```

Every transaction is threshold-signed and policy-checked.

## Balance

```bash
agenta sub balance
```

## Sign a message

```bash
agenta sub sign-message "Hello from AgentaOS"
```

## Sub-account details

```bash
agenta sub info <name>
```
