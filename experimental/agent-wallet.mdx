The agent wallet is an on-chain wallet that an AI agent operates, holding USDC or EURC. It is in private preview and available on request only: the CLI, the MCP server, and the Payment SDK do not include agent wallet tools. To ask for access, write to [contact@agentaos.ai](mailto:contact@agentaos.ai) and tell us what you need the wallet for.

The agent wallet is separate from stablecoin payouts. To receive your balance in USDC or EURC at a wallet address you control, see [Stablecoin payouts](/payouts/stablecoin-payouts).

To get paid, use the [payment tools](/mcp/setup), the [Payment SDK](/sdk/pay-overview), or the [CLI](/cli/install).
