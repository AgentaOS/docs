The financial infrastructure for businesses and AI agents. Three products, one platform.

<CardGroup cols={3}>
  <Card title="Accept Payments" icon="credit-card" href="/payments/introduction">
    Accept regulated stablecoin payments from your website. Create checkouts, verify webhooks, export invoices. **Stripe-like SDK for Node.js.**
  </Card>
  <Card title="Agent Wallets" icon="shield" href="/guardian/introduction">
    Give AI agents their own Ethereum accounts with threshold signing. Enforceable guardrails, delegated identity, no private key exposure.
  </Card>
  <Card title="x402 Protocol" icon="globe" href="/x402/introduction">
    HTTP-native payment protocol. Agents pay for API calls with a single header. Machine-to-machine commerce.
  </Card>

## Choose Your Path

<AccordionGroup>
  <Accordion title="I'm a merchant. I want to accept payments" icon="store" defaultOpen>
    Start with **[Payments](/payments/introduction)**. You'll create checkout sessions via the SDK, handle webhooks when customers pay, and export invoices for your accountant.

    ```bash
    npm install @agentaos/pay
    ```

    ```typescript
    const checkout = await agentaos.checkouts.create({
      amount: 49.99,
      currency: 'EUR',
      successUrl: 'https://myshop.com/success',
    });
    ```

    **Time to integrate:** ~30 minutes
  </Accordion>

  <Accordion title="I'm building an AI agent. I want it to transact" icon="robot">
    Start with **[Guardian Wallet](/guardian/introduction)**. Your agent gets a sovereign Ethereum account with threshold signing. The private key never exists.

    ```bash
    npm install -g agentaos && agenta login
    ```

    **Time to set up:** ~5 minutes
  </Accordion>

  <Accordion title="I'm building agent infrastructure. I want machine-to-machine payments" icon="code">
    Start with **[x402 Protocol](/x402/introduction)**. HTTP 402 Payment Required: agents pay for API calls with a payment header. No accounts, no sessions, just pay-per-request.

    **Time to integrate:** ~15 minutes
  </Accordion>
</AccordionGroup>
