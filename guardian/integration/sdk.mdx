# TypeScript SDK

The `@agentokratia/guardian-signer` package gives you a `ThresholdSigner` that works like any other Ethereum signer. Except the private key never exists.

## Install

```bash
npm install @agentokratia/guardian-signer
```

## Quick Start

```typescript
import { ThresholdSigner } from '@agentokratia/guardian-signer';

const signer = await ThresholdSigner.fromSecret({
  apiSecret: process.env.GUARDIAN_API_SECRET!,
  serverUrl: process.env.GUARDIAN_SERVER!,
  apiKey: process.env.GUARDIAN_API_KEY!,
});

// Sign and broadcast a transaction
const { txHash } = await signer.signTransaction({
  to: '0xRecipient...',
  value: '10000000000000000', // 0.01 ETH in wei
  network: 'base-sepolia',
});

// Always clean up —wipes share from memory
signer.destroy();
```

## ThresholdSigner

### `ThresholdSigner.fromSecret(opts)`

Create a signer from a base64-encoded API secret.

```typescript
const signer = await ThresholdSigner.fromSecret({
  apiSecret: string,   // Base64 key material (from dashboard or gw init)
  serverUrl: string,   // Guardian server URL
  apiKey: string,      // API key (gw_live_... or gw_test_...)
});
```

### `signer.signTransaction(tx)`

Sign and broadcast a transaction. Returns `{ txHash, signature }`.

```typescript
const result = await signer.signTransaction({
  to: '0x...',
  value: '1000000000000000',
  network: 'base-sepolia',
  data: '0x...',       // optional calldata
  gasLimit: '21000',   // optional
});

console.log(result.txHash);    // 0xabc...
console.log(result.signature); // 0x...
```

### `signer.signMessage(message)`

Sign an arbitrary message. Returns `{ signature, v, r, s }`.

```typescript
const result = await signer.signMessage('Hello from Guardian');
console.log(result.signature); // 0x...
console.log(result.v, result.r, result.s);
```

### `signer.toViemAccount()`

Get a viem-compatible custom account. Drop it into any viem wallet client.

```typescript
const account = signer.toViemAccount();
// account.address, account.signMessage, account.signTransaction, account.signTypedData
```

### `signer.destroy()`

Wipe the share from memory. Call this when done.

## Guardian (Facade)

For convenience, the `Guardian` class wraps both signing and read operations in one object.

```typescript
import { Guardian } from '@agentokratia/guardian-signer';

const gw = await Guardian.connect({
  apiSecret: process.env.GUARDIAN_API_SECRET!,
  serverUrl: process.env.GUARDIAN_SERVER!,
  apiKey: process.env.GUARDIAN_API_KEY!,
});

// Signing
const { txHash } = await gw.signTransaction({ to: '0x...', value: '0', network: 'base-sepolia' });

// Read operations
const health = await gw.getHealth();
const signers = await gw.listSigners();
const networks = await gw.listNetworks();
const balance = await gw.getBalance(signerId, 'base-sepolia');
const tokens = await gw.getTokenBalances(signerId, chainId);
const policies = await gw.getPolicies(signerId);
const audit = await gw.getAuditLog({ limit: 10 });

// Utilities
const resolved = await gw.resolveAddress('vitalik.eth');
const simResult = await gw.simulate(signerId, tx);

gw.destroy();
```

## viem Integration

Guardian plugs directly into viem's wallet client.

```typescript
import { ThresholdSigner } from '@agentokratia/guardian-signer';
import { createWalletClient, http, parseEther } from 'viem';
import { baseSepolia } from 'viem/chains';

const signer = await ThresholdSigner.fromSecret({
  apiSecret: process.env.GUARDIAN_API_SECRET!,
  serverUrl: process.env.GUARDIAN_SERVER!,
  apiKey: process.env.GUARDIAN_API_KEY!,
});

const client = createWalletClient({
  account: signer.toViemAccount(),
  chain: baseSepolia,
  transport: http(),
});

const hash = await client.sendTransaction({
  to: '0xRecipient...',
  value: parseEther('0.01'),
});

console.log('Tx:', hash);
signer.destroy();
```

## Vercel AI SDK

Use Guardian as a tool in the Vercel AI SDK.

```typescript
import { generateText, tool } from 'ai';
import { Guardian } from '@agentokratia/guardian-signer';
import { z } from 'zod';

const gw = await Guardian.connect({
  apiSecret: process.env.GUARDIAN_API_SECRET!,
  serverUrl: process.env.GUARDIAN_SERVER!,
  apiKey: process.env.GUARDIAN_API_KEY!,
});

const sendEth = tool({
  description: 'Send ETH to an address',
  parameters: z.object({
    to: z.string().describe('Recipient address'),
    amount: z.string().describe('Amount in wei'),
  }),
  execute: async ({ to, amount }) => {
    const { txHash } = await gw.signTransaction({
      to,
      value: amount,
      network: 'base-sepolia',
    });
    return { txHash };
  },
});

const { text } = await generateText({
  model: yourModel,
  tools: { sendEth },
  prompt: 'Send 0.01 ETH to 0xRecipient...',
});
```

## LangChain

Wrap Guardian as a LangChain tool.

```typescript
import { DynamicStructuredTool } from '@langchain/core/tools';
import { Guardian } from '@agentokratia/guardian-signer';
import { z } from 'zod';

const gw = await Guardian.connect({
  apiSecret: process.env.GUARDIAN_API_SECRET!,
  serverUrl: process.env.GUARDIAN_SERVER!,
  apiKey: process.env.GUARDIAN_API_KEY!,
});

const sendEthTool = new DynamicStructuredTool({
  name: 'send_eth',
  description: 'Send ETH using Guardian threshold signing',
  schema: z.object({
    to: z.string(),
    amount: z.string(),
  }),
  func: async ({ to, amount }) => {
    const { txHash } = await gw.signTransaction({
      to,
      value: amount,
      network: 'base-sepolia',
    });
    return `Sent. Tx: ${txHash}`;
  },
});
```

<Info>
  Every signing operation runs the full threshold signing protocol between your signer share and the server share. The full private key is never reconstructed. Guardrails evaluate every transaction server-side before co-signing.
</Info>
