# Supported Networks

Guardian Wallet signs transactions on any EVM chain.

<Info>
All EVM-compatible chains work out of the box. Guardian Wallet uses a pluggable chain architecture —if it speaks EVM, it signs.
</Info>

---

## How It Works

Guardian doesn't care which chain you target. The signing protocol operates on raw transaction hashes. The chain adapter handles serialization, gas estimation, and broadcasting.

Pick a network when you create a signer:

```bash
gw init --name my-agent --network base
```

Or specify it per transaction:

```bash
gw send 0xRecipient 0.01 --network arbitrum
```

## Adding a Custom Chain

Any EVM chain can be added via the chain adapter interface in `@agentokratia/guardian-chains`.

```typescript
import { IChainAdapter } from '@agentokratia/guardian-core';

class MyChainAdapter implements IChainAdapter {
  // Implement serialization, gas estimation, broadcasting
}
```

<Note>
The chain adapter is responsible for transaction serialization and broadcasting. The MPC signing protocol is chain-agnostic —it produces standard ECDSA signatures that work on any chain.
</Note>
